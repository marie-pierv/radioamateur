# 📡 RadioAmateur Exam Practice Platform (Canada / ISDE)

An interactive platform to help users prepare for the Canadian amateur radio (ISDE) exams through:

- Practice quizzes (custom or exam-like)
- Progress tracking and statistics
- Structured learning courses with interactive content
- Coverage validation between course content and official questions

---

## 🧠 Data Model Overview

The system is composed of several domains:

- 👤 Users
- 📚 Question Bank
- 📝 Exam Sessions & Attempts
- 🎓 Courses & Widgets
- 📊 Progress Tracking
